## Pourquoi Senrigan ?

<div class="grid cards" markdown>

-   :material-laptop:{ .lg .middle } __Hors ligne et autonome__

    ---

    Fonctionne entièrement sur votre ordinateur portable avec une seule commande `make up` — **aucun SIEM, aucune infrastructure cloud**.

-   :material-target:{ .lg .middle } __Plus de 100 hunts intégrés__

    ---

    Threat hunts AWS CloudTrail prêts à l'emploi couvrant la compromission, l'élévation de privilèges et l'exfiltration.

-   :material-robot:{ .lg .middle } __Analyse par chat IA__

    ---

    Examinez vos données CloudTrail en langage naturel grâce à une analyse assistée par IA.

-   :material-chart-box:{ .lg .middle } __Plus de 80 graphiques de tableau de bord__

    ---

    Tableaux de bord BI Apache **Superset** préconçus pour visualiser l'activité en un coup d'œil.

-   :material-file-document:{ .lg .middle } __Rapports et Suzaku__

    ---

    Générez des rapports de threat hunting au format HTML et visualisez les résultats [Suzaku](https://github.com/Yamato-Security/suzaku).

-   :material-graph:{ .lg .middle } __Graphe de ressources AWS Config__

    ---

    Explorez les ressources de votre compte et leurs relations sous forme de graphe.

</div>
