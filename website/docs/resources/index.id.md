## Ucapan Terima Kasih

Proyek ini ada berkat proyek-proyek dan dataset luar biasa ini :)

- [Apache Superset](https://superset.apache.org/) — platform BI
- [AWS CloudTrail Lake query samples](https://github.com/aws-samples/cloud-trail-lake-query-samples) — contoh kueri CloudTrail Lake
- [AWS Incident Response](https://github.com/easttimor/aws-incident-response/) - playbook dan alat respons insiden AWS
- [DuckDB](https://duckdb.org/) — basis data analitik tertanam
- [flaws.cloud](http://flaws.cloud) — dataset AWS CloudTrail yang sengaja dibuat rentan
- [MaxMind GeoLite2](https://dev.maxmind.com/geoip/geolite2-free-geolocation-data) — basis data GeoIP
- [SIEM on Amazon OpenSearch Service](https://github.com/aws-samples/siem-on-amazon-opensearch-service) — implementasi referensi analitik CloudTrail mirip SIEM
- [Suzaku](https://github.com/Yamato-Security/suzaku) — Suzaku, alat analisis log CloudTrail yang dibuat oleh Yamato Security
- [Yamato Security](https://github.com/Yamato-Security) — [suzaku-sample-data](https://github.com/Yamato-Security/suzaku-sample-data)
