## ကျေးဇူးတင်လွှာ

ဤပရောဂျက်သည် ဤအံ့ဖွယ်ကောင်းသော ပရောဂျက်များနှင့် ဒေတာအစုများကြောင့် တည်ရှိနေခြင်းဖြစ်သည် :)

- [Apache Superset](https://superset.apache.org/) — BI ပလက်ဖောင်း
- [AWS CloudTrail Lake query samples](https://github.com/aws-samples/cloud-trail-lake-query-samples) — CloudTrail Lake query နမူနာများ
- [AWS Incident Response](https://github.com/easttimor/aws-incident-response/) - AWS အဖြစ်အပျက်တုံ့ပြန်မှု playbook များနှင့် ကိရိယာများ
- [DuckDB](https://duckdb.org/) — embedded analytical database
- [flaws.cloud](http://flaws.cloud) — ရည်ရွယ်ချက်ရှိရှိ အားနည်းချက်ထည့်သွင်းထားသော AWS CloudTrail ဒေတာအစု
- [MaxMind GeoLite2](https://dev.maxmind.com/geoip/geolite2-free-geolocation-data) — GeoIP ဒေတာဘေ့စ်များ
- [SIEM on Amazon OpenSearch Service](https://github.com/aws-samples/siem-on-amazon-opensearch-service) — SIEM ပုံစံ CloudTrail analytics ကိုးကားအကောင်အထည်ဖော်မှု
- [Suzaku](https://github.com/Yamato-Security/suzaku) — Suzaku၊ Yamato Security မှ ဖန်တီးထားသော CloudTrail log ခွဲခြမ်းစိတ်ဖြာရေးကိရိယာ
- [Yamato Security](https://github.com/Yamato-Security) — [suzaku-sample-data](https://github.com/Yamato-Security/suzaku-sample-data)
