## आभार

यह परियोजना इन शानदार परियोजनाओं और डेटासेट के कारण अस्तित्व में है :)

- [Apache Superset](https://superset.apache.org/) — BI प्लेटफ़ॉर्म
- [AWS CloudTrail Lake query samples](https://github.com/aws-samples/cloud-trail-lake-query-samples) — CloudTrail Lake क्वेरी उदाहरण
- [AWS Incident Response](https://github.com/easttimor/aws-incident-response/) - AWS घटना प्रतिक्रिया प्लेबुक और उपकरण
- [DuckDB](https://duckdb.org/) — एम्बेडेड विश्लेषणात्मक डेटाबेस
- [flaws.cloud](http://flaws.cloud) — जानबूझकर असुरक्षित बनाया गया AWS CloudTrail डेटासेट
- [MaxMind GeoLite2](https://dev.maxmind.com/geoip/geolite2-free-geolocation-data) — GeoIP डेटाबेस
- [SIEM on Amazon OpenSearch Service](https://github.com/aws-samples/siem-on-amazon-opensearch-service) — SIEM-जैसा CloudTrail विश्लेषण संदर्भ कार्यान्वयन
- [Suzaku](https://github.com/Yamato-Security/suzaku) — Suzaku, Yamato Security द्वारा बनाया गया एक CloudTrail लॉग विश्लेषण उपकरण
