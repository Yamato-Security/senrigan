## Teşekkürler

Bu proje, şu harika projeler ve veri kümeleri sayesinde var :)

- [Apache Superset](https://superset.apache.org/) — BI platformu
- [AWS CloudTrail Lake query samples](https://github.com/aws-samples/cloud-trail-lake-query-samples) — CloudTrail Lake sorgu örnekleri
- [AWS Incident Response](https://github.com/easttimor/aws-incident-response/) - AWS olay müdahale taktik kitapları ve araçları
- [DuckDB](https://duckdb.org/) — gömülü analitik veritabanı
- [flaws.cloud](http://flaws.cloud) — kasıtlı olarak savunmasız bırakılmış AWS CloudTrail veri kümesi
- [MaxMind GeoLite2](https://dev.maxmind.com/geoip/geolite2-free-geolocation-data) — GeoIP veritabanları
- [SIEM on Amazon OpenSearch Service](https://github.com/aws-samples/siem-on-amazon-opensearch-service) — SIEM benzeri CloudTrail analitiği referans uygulaması
- [Suzaku](https://github.com/Yamato-Security/suzaku) — Yamato Security tarafından oluşturulan bir CloudTrail günlük analizi aracı olan Suzaku
- [Yamato Security](https://github.com/Yamato-Security) — [suzaku-sample-data](https://github.com/Yamato-Security/suzaku-sample-data)
