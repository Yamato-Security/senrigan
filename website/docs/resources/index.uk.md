## Подяки

Цей проєкт існує завдяки цим чудовим проєктам і наборам даних :)

- [Apache Superset](https://superset.apache.org/) — платформа BI
- [AWS CloudTrail Lake query samples](https://github.com/aws-samples/cloud-trail-lake-query-samples) — приклади запитів CloudTrail Lake
- [AWS Incident Response](https://github.com/easttimor/aws-incident-response/) - плейбуки та інструменти реагування на інциденти AWS
- [DuckDB](https://duckdb.org/) — вбудована аналітична база даних
- [flaws.cloud](http://flaws.cloud) — навмисно вразливий набір даних AWS CloudTrail
- [MaxMind GeoLite2](https://dev.maxmind.com/geoip/geolite2-free-geolocation-data) — бази даних GeoIP
- [SIEM on Amazon OpenSearch Service](https://github.com/aws-samples/siem-on-amazon-opensearch-service) — еталонна реалізація SIEM-подібної аналітики CloudTrail
- [Suzaku](https://github.com/Yamato-Security/suzaku) — Suzaku, інструмент аналізу журналів CloudTrail, створений Yamato Security
- [Yamato Security](https://github.com/Yamato-Security) — [suzaku-sample-data](https://github.com/Yamato-Security/suzaku-sample-data)
