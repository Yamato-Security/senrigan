## 감사의 말

이 프로젝트는 다음의 훌륭한 프로젝트와 데이터셋 덕분에 존재합니다 :)

- [Apache Superset](https://superset.apache.org/) — BI 플랫폼
- [AWS CloudTrail Lake query samples](https://github.com/aws-samples/cloud-trail-lake-query-samples) — CloudTrail Lake 쿼리 예제
- [AWS Incident Response](https://github.com/easttimor/aws-incident-response/) - AWS 사고 대응 플레이북 및 도구
- [DuckDB](https://duckdb.org/) — 임베디드 분석 데이터베이스
- [flaws.cloud](http://flaws.cloud) — 의도적으로 취약하게 만든 AWS CloudTrail 데이터셋
- [MaxMind GeoLite2](https://dev.maxmind.com/geoip/geolite2-free-geolocation-data) — GeoIP 데이터베이스
- [SIEM on Amazon OpenSearch Service](https://github.com/aws-samples/siem-on-amazon-opensearch-service) — SIEM과 유사한 CloudTrail 분석 참조 구현
- [Suzaku](https://github.com/Yamato-Security/suzaku) — Yamato Security가 만든 CloudTrail 로그 분석 도구 Suzaku
- [Yamato Security](https://github.com/Yamato-Security) — [suzaku-sample-data](https://github.com/Yamato-Security/suzaku-sample-data)
