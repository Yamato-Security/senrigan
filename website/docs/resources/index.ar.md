## الشكر والتقدير

هذا المشروع موجود بفضل هذه المشاريع ومجموعات البيانات الرائعة :)

- [Apache Superset](https://superset.apache.org/) — منصة ذكاء الأعمال
- [AWS CloudTrail Lake query samples](https://github.com/aws-samples/cloud-trail-lake-query-samples) — أمثلة استعلامات CloudTrail Lake
- [AWS Incident Response](https://github.com/easttimor/aws-incident-response/) - أدلة وأدوات الاستجابة للحوادث في AWS
- [DuckDB](https://duckdb.org/) — قاعدة بيانات تحليلية مدمجة
- [flaws.cloud](http://flaws.cloud) — مجموعة بيانات AWS CloudTrail مصممة عمدًا لتكون قابلة للاختراق
- [MaxMind GeoLite2](https://dev.maxmind.com/geoip/geolite2-free-geolocation-data) — قواعد بيانات GeoIP
- [SIEM on Amazon OpenSearch Service](https://github.com/aws-samples/siem-on-amazon-opensearch-service) — تطبيق مرجعي لتحليلات CloudTrail شبيه بـ SIEM
- [Suzaku](https://github.com/Yamato-Security/suzaku) — Suzaku، أداة تحليل سجلات CloudTrail التي أنشأتها Yamato Security
- [Yamato Security](https://github.com/Yamato-Security) — [suzaku-sample-data](https://github.com/Yamato-Security/suzaku-sample-data)
