## 謝辞

このプロジェクトは、これらの素晴らしいプロジェクトとデータセットのおかげで成り立っています :)

- [Apache Superset](https://superset.apache.org/) — BI プラットフォーム
- [AWS CloudTrail Lake query samples](https://github.com/aws-samples/cloud-trail-lake-query-samples) — CloudTrail Lake クエリの例
- [AWS Incident Response](https://github.com/easttimor/aws-incident-response/) - AWS インシデント対応のプレイブックとツール
- [DuckDB](https://duckdb.org/) — 組み込み型分析データベース
- [flaws.cloud](http://flaws.cloud) — 意図的に脆弱性を持たせた AWS CloudTrail データセット
- [MaxMind GeoLite2](https://dev.maxmind.com/geoip/geolite2-free-geolocation-data) — GeoIP データベース
- [SIEM on Amazon OpenSearch Service](https://github.com/aws-samples/siem-on-amazon-opensearch-service) — SIEM ライクな CloudTrail 分析のリファレンス実装
- [Suzaku](https://github.com/Yamato-Security/suzaku) — Suzaku、Yamato Security が作成した CloudTrail ログ分析ツール
- [Yamato Security](https://github.com/Yamato-Security) — [suzaku-sample-data](https://github.com/Yamato-Security/suzaku-sample-data)
