## กิตติกรรมประกาศ

โปรเจกต์นี้เกิดขึ้นได้ด้วยโปรเจกต์และชุดข้อมูลที่ยอดเยี่ยมเหล่านี้ :)

- [Apache Superset](https://superset.apache.org/) — แพลตฟอร์ม BI
- [AWS CloudTrail Lake query samples](https://github.com/aws-samples/cloud-trail-lake-query-samples) — ตัวอย่างคิวรีของ CloudTrail Lake
- [AWS Incident Response](https://github.com/easttimor/aws-incident-response/) - เพลย์บุกและเครื่องมือสำหรับการตอบสนองต่อเหตุการณ์ของ AWS
- [DuckDB](https://duckdb.org/) — ฐานข้อมูลเชิงวิเคราะห์แบบฝังตัว
- [flaws.cloud](http://flaws.cloud) — ชุดข้อมูล AWS CloudTrail ที่จงใจสร้างให้มีช่องโหว่
- [MaxMind GeoLite2](https://dev.maxmind.com/geoip/geolite2-free-geolocation-data) — ฐานข้อมูล GeoIP
- [SIEM on Amazon OpenSearch Service](https://github.com/aws-samples/siem-on-amazon-opensearch-service) — การนำไปใช้อ้างอิงสำหรับการวิเคราะห์ CloudTrail แบบ SIEM
- [Suzaku](https://github.com/Yamato-Security/suzaku) — Suzaku เครื่องมือวิเคราะห์ล็อก CloudTrail ที่สร้างโดย Yamato Security
- [Yamato Security](https://github.com/Yamato-Security) — [suzaku-sample-data](https://github.com/Yamato-Security/suzaku-sample-data)
