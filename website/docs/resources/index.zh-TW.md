## 致謝

本專案的存在要感謝這些優秀的專案與資料集 :)

- [Apache Superset](https://superset.apache.org/) — BI 平台
- [AWS CloudTrail Lake query samples](https://github.com/aws-samples/cloud-trail-lake-query-samples) — CloudTrail Lake 查詢範例
- [AWS Incident Response](https://github.com/easttimor/aws-incident-response/) - AWS 事件回應的劇本與工具
- [DuckDB](https://duckdb.org/) — 嵌入式分析資料庫
- [flaws.cloud](http://flaws.cloud) — 刻意設計為含有漏洞的 AWS CloudTrail 資料集
- [MaxMind GeoLite2](https://dev.maxmind.com/geoip/geolite2-free-geolocation-data) — GeoIP 資料庫
- [SIEM on Amazon OpenSearch Service](https://github.com/aws-samples/siem-on-amazon-opensearch-service) — 類 SIEM 的 CloudTrail 分析參考實作
- [Suzaku](https://github.com/Yamato-Security/suzaku) — Suzaku，由 Yamato Security 開發的 CloudTrail 日誌分析工具
- [Yamato Security](https://github.com/Yamato-Security) — [suzaku-sample-data](https://github.com/Yamato-Security/suzaku-sample-data)
