## Remerciements

Ce projet existe grâce à ces merveilleux projets et jeux de données :)

- [Apache Superset](https://superset.apache.org/) — plateforme de BI
- [AWS CloudTrail Lake query samples](https://github.com/aws-samples/cloud-trail-lake-query-samples) — exemples de requêtes CloudTrail Lake
- [AWS Incident Response](https://github.com/easttimor/aws-incident-response/) - playbooks et outils de réponse aux incidents AWS
- [DuckDB](https://duckdb.org/) — base de données analytique embarquée
- [flaws.cloud](http://flaws.cloud) — jeu de données AWS CloudTrail intentionnellement vulnérable
- [MaxMind GeoLite2](https://dev.maxmind.com/geoip/geolite2-free-geolocation-data) — bases de données GeoIP
- [SIEM on Amazon OpenSearch Service](https://github.com/aws-samples/siem-on-amazon-opensearch-service) — implémentation de référence d'analyse CloudTrail de type SIEM
- [Suzaku](https://github.com/Yamato-Security/suzaku) — Suzaku, un outil d'analyse de logs CloudTrail créé par Yamato Security
- [Yamato Security](https://github.com/Yamato-Security) — [suzaku-sample-data](https://github.com/Yamato-Security/suzaku-sample-data)
