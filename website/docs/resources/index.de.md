## Danksagungen

Dieses Projekt existiert dank dieser wunderbaren Projekte und Datensätze :)

- [Apache Superset](https://superset.apache.org/) — BI-Plattform
- [AWS CloudTrail Lake query samples](https://github.com/aws-samples/cloud-trail-lake-query-samples) — CloudTrail-Lake-Abfragebeispiele
- [AWS Incident Response](https://github.com/easttimor/aws-incident-response/) - AWS-Incident-Response-Playbooks und -Tools
- [DuckDB](https://duckdb.org/) — eingebettete analytische Datenbank
- [flaws.cloud](http://flaws.cloud) — absichtlich verwundbarer AWS-CloudTrail-Datensatz
- [MaxMind GeoLite2](https://dev.maxmind.com/geoip/geolite2-free-geolocation-data) — GeoIP-Datenbanken
- [SIEM on Amazon OpenSearch Service](https://github.com/aws-samples/siem-on-amazon-opensearch-service) — SIEM-ähnliche Referenzimplementierung für CloudTrail-Analytik
- [Suzaku](https://github.com/Yamato-Security/suzaku) — Suzaku, ein von Yamato Security entwickeltes CloudTrail-Log-Analysetool
- [Yamato Security](https://github.com/Yamato-Security) — [suzaku-sample-data](https://github.com/Yamato-Security/suzaku-sample-data)
