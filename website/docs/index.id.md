## Mengapa Senrigan?

<div class="grid cards" markdown>

-   :material-laptop:{ .lg .middle } __Offline & mandiri__

    ---

    Berjalan sepenuhnya di laptop Anda hanya dengan satu `make up` — **tanpa SIEM, tanpa infrastruktur cloud**.

-   :material-target:{ .lg .middle } __100+ hunt bawaan__

    ---

    Threat hunt AWS CloudTrail siap pakai yang mencakup kompromi, eskalasi hak istimewa, dan eksfiltrasi.

-   :material-robot:{ .lg .middle } __Analisis chat AI__

    ---

    Selidiki data CloudTrail Anda dalam bahasa alami dengan analisis berbantuan AI.

-   :material-chart-box:{ .lg .middle } __80+ chart dashboard__

    ---

    Dashboard BI Apache **Superset** siap pakai untuk memvisualisasikan aktivitas secara sekilas.

-   :material-file-document:{ .lg .middle } __Laporan & Suzaku__

    ---

    Hasilkan laporan threat-hunting HTML dan visualisasikan hasil [Suzaku](https://github.com/Yamato-Security/suzaku).

-   :material-graph:{ .lg .middle } __Grafik sumber daya AWS Config__

    ---

    Jelajahi sumber daya akun Anda dan hubungannya sebagai sebuah grafik.

</div>
