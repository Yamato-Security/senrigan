## Senrigan क्यों?

<div class="grid cards" markdown>

-   :material-laptop:{ .lg .middle } __ऑफ़लाइन और स्व-निहित__

    ---

    आपके लैपटॉप पर पूरी तरह से एक ही `make up` के साथ चलता है — **कोई SIEM नहीं, कोई क्लाउड इंफ्रास्ट्रक्चर नहीं**।

-   :material-target:{ .lg .middle } __100+ अंतर्निहित हंट__

    ---

    तैयार-चलाने-योग्य AWS CloudTrail थ्रेट हंट जो समझौता, विशेषाधिकार वृद्धि और एक्सफ़िल्ट्रेशन को कवर करते हैं।

-   :material-robot:{ .lg .middle } __AI चैट विश्लेषण__

    ---

    AI-सहायता प्राप्त विश्लेषण के साथ प्राकृतिक भाषा में अपने CloudTrail डेटा की जांच करें।

-   :material-chart-box:{ .lg .middle } __80+ डैशबोर्ड चार्ट__

    ---

    गतिविधि को एक नज़र में देखने के लिए पूर्व-निर्मित Apache **Superset** BI डैशबोर्ड।

-   :material-file-document:{ .lg .middle } __रिपोर्ट और Suzaku__

    ---

    HTML थ्रेट-हंटिंग रिपोर्ट जनरेट करें और [Suzaku](https://github.com/Yamato-Security/suzaku) परिणामों को विज़ुअलाइज़ करें।

-   :material-graph:{ .lg .middle } __AWS Config संसाधन ग्राफ__

    ---

    अपने खाते के संसाधनों और उनके संबंधों को एक ग्राफ के रूप में एक्सप्लोर करें।

</div>
