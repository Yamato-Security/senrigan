# Senrigan क्या है?

## मिनटों में AWS खतरों का शिकार करें — कोई SIEM आवश्यक नहीं, किसी Cloud इन्फ्रास्ट्रक्चर की आवश्यकता नहीं
> अपने CloudTrail लॉग्स डालें और 100+ तैयार-से-चलने वाले थ्रेट हंट्स, एक BI डैशबोर्ड, और AI-सहायता प्राप्त विश्लेषण पाएं
> — सब कुछ आपके लैपटॉप पर एक ही `make up` के साथ।

## किसके लिए डिज़ाइन किया गया
- 🔍 सुरक्षा इंजीनियर — AWS अकाउंट के समझौते, विशेषाधिकार वृद्धि, या डेटा बहिष्करण की जांच करने वाले
