# 什麼是 Senrigan？

## 在數分鐘內獵捕 AWS 威脅 — 無需 SIEM，也不需要任何雲端基礎架構
> 只要放入您的 CloudTrail 日誌，即可獲得 100 多項可立即執行的威脅獵捕、一個 BI 儀表板，以及 AI 輔助分析
> — 全部都能在您的筆記型電腦上透過單一指令 `make up` 完成。

## 適用對象
- 🔍 安全工程師 — 調查 AWS 帳戶遭入侵、權限提升或資料外洩
- 🛡 雲端安全團隊 — 在沒有專屬 SIEM 的情況下執行定期的雲端態勢檢視
- 🧑‍💻 開發人員與 SRE — 在事件發生期間或之後快速稽核自己帳戶的 CloudTrail 歷史紀錄
