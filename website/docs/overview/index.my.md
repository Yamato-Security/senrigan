# Senrigan ဆိုသည်မှာ ဘာလဲ။

## AWS ခြိမ်းခြောက်မှုများကို မိနစ်ပိုင်းအတွင်း ရှာဖွေပါ — SIEM မလို၊ Cloud အခြေခံအဆောက်အအုံ မလိုအပ်ပါ
> သင်၏ CloudTrail logs များကို ထည့်လိုက်ရုံဖြင့် အသင့်အသုံးပြုနိုင်သော ခြိမ်းခြောက်မှုရှာဖွေမှု ၁၀၀+၊ BI dashboard တစ်ခုနှင့် AI ဖြင့်အကူအညီပေးသော ခွဲခြမ်းစိတ်ဖြာမှုကို ရရှိပါမည်
> — အားလုံးကို သင်၏ laptop ပေါ်တွင် `make up` တစ်ခုတည်းဖြင့်။

## ဒီဇိုင်းရည်ရွယ်ထားသူများ
- 🔍 လုံခြုံရေး အင်ဂျင်နီယာများ — AWS account အပေါက်ဖောက်ခံရမှု၊ အခွင့်အရေးမြှင့်တင်မှု သို့မဟုတ် ဒေတာ ထုတ်ယူမှုကို စုံစမ်းစစ်ဆေးခြင်း
- 🛡 Cloud လုံခြုံရေး အဖွဲ့များ — သီးသန့် SIEM မရှိဘဲ ပုံမှန် cloud အနေအထား ပြန်လည်သုံးသပ်မှုများ ပြုလုပ်ခြင်း
- 🧑‍💻 Developer များနှင့် SRE များ — ဖြစ်ရပ်တစ်ခုအတွင်း သို့မဟုတ် ဖြစ်ပြီးနောက် မိမိ၏ account ၏ CloudTrail မှတ်တမ်းကို မြန်ဆန်စွာ စစ်ဆေးခြင်း
