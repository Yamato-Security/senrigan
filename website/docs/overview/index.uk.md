# Що таке Senrigan?

## Полювання на загрози в AWS за лічені хвилини — без SIEM, без хмарної інфраструктури
> Завантажте свої журнали CloudTrail і отримайте 100+ готових до запуску полювань на загрози, BI-панель та аналіз із допомогою ШІ
> — усе це на вашому ноутбуці однією командою `make up`.

- 🔍 Інженерів з безпеки — які розслідують компрометацію облікового запису AWS, підвищення привілеїв або викрадення даних
