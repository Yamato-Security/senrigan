# Was ist Senrigan?

## Bedrohungen in AWS in Minuten aufspüren — kein SIEM erforderlich, keine Cloud-Infrastruktur nötig
> Laden Sie einfach Ihre CloudTrail-Logs hoch und erhalten Sie über 100 sofort einsetzbare Bedrohungssuchen, ein BI-Dashboard und KI-gestützte Analyse
> — alles auf Ihrem Laptop mit einem einzigen `make up`.

## Konzipiert für
- 🔍 Security Engineers — die eine Kompromittierung eines AWS-Kontos, Rechteausweitung oder Datenexfiltration untersuchen
- 🛡 Cloud-Security-Teams — die regelmäßige Überprüfungen der Cloud-Sicherheitslage ohne ein dediziertes SIEM durchführen
- 🧑‍💻 Entwickler und SREs — die während oder nach einem Vorfall schnell den CloudTrail-Verlauf ihres eigenen Kontos auditieren
