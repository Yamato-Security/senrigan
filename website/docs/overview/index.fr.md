# Qu'est-ce que Senrigan ?

## Traquez les menaces AWS en quelques minutes — sans SIEM, sans infrastructure Cloud
> Importez vos journaux CloudTrail et obtenez plus de 100 traques de menaces prêtes à l'emploi, un tableau de bord BI et une analyse assistée par IA
> — le tout sur votre ordinateur portable avec une simple commande `make up`.

## Conçu pour
- 🔍 Les ingénieurs en sécurité — qui enquêtent sur la compromission d'un compte AWS, l'élévation de privilèges ou l'exfiltration de données
- 🛡 Les équipes de sécurité Cloud — qui réalisent des revues périodiques de la posture cloud sans SIEM dédié
- 🧑‍💻 Les développeurs et SRE — qui auditent rapidement l'historique CloudTrail de leur propre compte pendant ou après un incident
