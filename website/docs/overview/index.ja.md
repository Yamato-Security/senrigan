# Senriganとは？

## AWSの脅威を数分でハント — SIEM不要、クラウドインフラ不要
> CloudTrailのログを投入するだけで、すぐに実行できる100以上の脅威ハント、BIダッシュボード、AI支援による分析が手に入ります
> — すべて単一の `make up` でラップトップ上で完結します。

## 想定される利用者
- 🔍 セキュリティエンジニア — AWSアカウントの侵害、権限昇格、データ持ち出しを調査する方
- 🛡 クラウドセキュリティチーム — 専用のSIEMを持たずに定期的なクラウドポスチャレビューを実施する方
- 🧑‍💻 開発者およびSRE — インシデントの最中または後に、自身のアカウントのCloudTrail履歴を素早く監査する方
