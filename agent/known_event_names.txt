# Verified AWS API names used by builtin_hunts.yaml
#
# Every string a hunt compares against `event_name` must appear here, and every
# name here must be used by at least one hunt (agent/tests/test_builtin_hunts_phase7.py
# enforces both directions). The list exists because a misspelled API name is
# invisible: the SQL runs, returns zero rows, and an analyst reads that as
# "no attack". Cross-checking builtin_hunts.yaml against the AWS incident
# response playbooks found two such names already shipped —
# `CreateOIDCProvider` (IAM spells it `CreateOpenIDConnectProvider`) and
# `DisableDetector` (GuardDuty has no such API).
#
# Before adding a name, confirm it in the service's API reference — the
# CloudTrail `eventName` is the API action name, which is not always the
# console wording or the CLI subcommand.
#
